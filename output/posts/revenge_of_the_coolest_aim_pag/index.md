The [web page as service](http://presentations.lawver.net/standards/supernova_2006_modular_web_dev/) thing I talked about before is live now, and I've built my first module that uses it. If you go to [my profile](http://www.aimpages.com/kplawver/profile.html), you'll see a little module in the left-hand column called [shared buddies](http://iamalpha.com/.module/shared-buddies) (if you want to see the source) that, if you're logged in and have a profile, will grab the buddy gallery and see which buddies we share. Isn't that cool?\\ I'm looking for other ideas for modules to mash up people's pages, so be on the lookout for other cool stuff. If you've got ideas, please post a comment!
