<p>To expand a bit, there's no way to build something on the web without HTML—even if that HTML is written via JavaScript.</p><p>Similarly, there's no (reasonable) way to adjust the appearance of that HTML without CSS—even if that CSS is written via JavaScript.</p><p>These days, HTML and CSS can handle massive amounts of things that used to require JavaScript.</p><p>So if JavaScript is the least critical and least reliable part of the stack, we should all strive to use it less rather than more.</p>
