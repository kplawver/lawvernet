I've started my [Blogger API](http://plant.blogger.com/api) project! I'm calling it [BlogTcl](/blogtcl). It will be an XML-RPC implementation for [AOLserver](http://www.aolserver.com) and I've laid out the skeleton of the Tcl code with proc names and some documentation. Wow, my first open source project. I feel like such a geek.
