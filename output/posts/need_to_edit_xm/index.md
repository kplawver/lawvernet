On the recommendation of a coworker, I tried out [Oxygen](http://www.oxygenxml.com/) last week, and I love it. It's a great XML/XSL editor and debugger, with in-place validation and transformation, and useful error messages. So, if you need to write some XML or XSL, check it out. Best part... it runs on OS X, Windows or Linux, and it's got the smoothest Java GUI I've ever seen. Very well done!
