Do you use multiple computers? Are they all running different OS'es? Do you use different text editors on each one? Does that piss you off? You're in luck, my friend!! Go download [jEdit](http://www.jedit.org) today. It's a full-functioned text editor written in Java and delivered as an executable jar file. So, any platform that can run Java can run jEdit. Problem of the text editor collection - SOLVED!! It also has an impressive array of plug-ins which are awesome. Go get the latest stable build and check it out. You'll love it.
