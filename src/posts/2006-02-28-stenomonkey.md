I dread taking minutes at working group meetings because it usually means projecting a text editor which is hard to read for the other people in the meeting, and hard to edit for the minute taker. I've used IRC, but I hate that the minutes get polluted by the "back channel" discussion. On the flight over, I thought to myself, "Hey, I could easily make a little web app to do this." [Here it is](http://dev.lawver.net/stenomonkey). Everything is stored in the DOM, and there's no save back to the server which is an issue. It would be nice to have a backend store for minutes to make sure there's a backup in case of a browser crash, but I did this between the plane and jet lag. I also haven't tested it in anything but Firefox and Safari. If it works for you, great. If not, sorry.
