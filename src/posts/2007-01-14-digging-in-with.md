It's the end of our first full week of development on our big Rails experiment, and I couldn't be happier with how things are going. We have 90% of the admin interface done (user management, static page stuff, moderation, etc), have user logins working using a _really_ cool upcoming AOL open API (should be able to talk more about it later this week, but it's one of the best web services I've ever used and I'm not saying that because I work there), and users can edit their own content now in a limited manner.

[Rails](http://rubyonrails.org) makes things _so_ easy. It takes all the obnoxious bits out of building web apps: the plumbing. I no longer have to write hundreds of lines of code before I can actually do anything important.

This is also my first experience with [Subversion](http://subversion.tigris.org/), and I'm loving that too. We've been using [svnX](http://www.lachoseinteractive.net/en/community/subversion/svnx/features/), and I'm loving that too. It took a minute to get used to, but I _love_ smart mode. It tells me what I've changed so I don't have to go digging for it to make sure I've checked everything in (so [Jason](http://sixtwothree.org) can keep his stuff in sync and mostly working).

We're still planning on launching before [SxSW](http://2007.sxsw.com/interactive..). wish us luck.
