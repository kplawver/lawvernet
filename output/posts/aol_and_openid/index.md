[John spilled the beans](http://journals.aol.com/panzerjohn/abstractioneer/entries/2007/02/15/aol-and-openid-where-we-are/1406) so I will too. AOL is doing [OpenID](http://openidenabled.com)! AOL is currently an identity provider (meaning you can log in on third-party openid-enabled sites using your spanking new OpenID URL, for example: http://openid.aol.com/kplawver), and we're working on accepting OpenID logins on AOL products, but that's going to take some time. See [John's post for all the details](http://journals.aol.com/panzerjohn/abstractioneer/entries/2007/02/15/aol-and-openid-where-we-are/1406).\\ This is really exciting for me. It's another sign of us opening up, supporting emerging standards and trying new things. It means I won't be all alone next month when we launch the super-secret [Rails](http://rubyonrails.com) project, which will accept OpenID logins.\\ Now, back to work so we can launch this thing on time and I can tell you all about it.
