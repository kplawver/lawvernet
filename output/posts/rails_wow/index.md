I've been flirting with it for a while (have had the book since it came out and installed Rails all over the place, just never had time to get into it), but last night I broke down and built my first web application with [Ruby on Rails](http://rubyonrails.com) and all I have to say is **wow**. That was way easier than it should have been. Granted, it was painfully simple, but still, it was about an hour total between setting up the domain and database on [Dreamhost](http://www.dreamhost.com/rewards.cgi?kplawver) to getting it tweaked and looking like I wanted (oh, and working). It was another 5 minutes with the book this morning to get the export feature working like I wanted (well, _they_ wanted).\\ Next time I need to build something outside of work (or hell, maybe inside of work), it'll most likely be in Rails.
