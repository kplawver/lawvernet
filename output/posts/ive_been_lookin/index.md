I've been looking at some very well done blog sites lately, and have had cool border envy. I started poking around the source and saw that in most case all these people who have cool borders are using tables! I thought for sure they'd discovered some secret CSS code to use to make things work. Nope, just tables. Since that was no challenge, I decided that I need to do neat-o borders without tables. So, you should now notice that there is only one table on any of the main pages, and it's just to hold the [about me](/about.html) list o' crap. Pattin' myself on the back right now, let me tell you.
