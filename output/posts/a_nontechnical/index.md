I was asked by someone at work to come up with a non-technical definition of [microformats](http://microformats.org) for some glossary of web terms they're putting together. Here's what I came up with:\\ bq. Using standards that exist today, microformats take the HTML used to build the web and turn it into powerful, semantic, machine-readable, web-service ready data - without changing the specification or changing how HTML is written or delivered.\\ And here's what the amazing [Paul Downey](http://blog.whatfettle.com) came up with on [Twitter](http://twitter.com/psd/statuses/2713573)\\ bq. Microformats for non-techies: colours on a Web page for things such as "date" and "telephone number" which only computers can see\\ I like Paul's better. Oh, and you should check out [Paul's presentation on Web API's](http://blog.whatfettle.com/2007/01/11/good-web-apis-are-just-web-sites/). The man creates the best slides in the business.
