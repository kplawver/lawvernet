If I ever start a punk ska band, it's going to be called **[Cryptosporidium](http://www.nal.usda.gov/wqic/cornell.html) Toothpaste**. I should never blog while ill. Nor will I ever not eat for twelve hours. Thus endeth the stupidest post ever.
