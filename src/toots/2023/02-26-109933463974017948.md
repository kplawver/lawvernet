<p>Last night the 11yo broke down the Google Slides middle school Chatroom for me:</p><p>1. At first they used a Google doc but the infinite scroll was too chaotic<br>2. In the slide deck each new slide is one “post”—some all text, some images, some both—<br>3. They use slides’ comments feature to “reply” to each other’s “posts”<br>4. This allows participants to easily flip between posts using the slide thumbnail navigation, so they can find the conversations they care about easily<br>5. He owns the file &amp; if anyone spams it, deletes other people’s posts, or gets nasty, he can revert the file to its previous save state &amp; remove the spammer’s access<br>6. He did share the file with me on purpose, I think because he was proud &amp; wanted me to see what he’d made</p><p>Essentially they’ve created a chatroom with moderation in Google Slides, so they can get around the school’s ban on platforms like Discord. It’s kind of brilliant</p>
